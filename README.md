# Sandy Wiraabdy - Interactive Portfolio

A highly interactive, minimalist portfolio website designed to showcase creative development and UI/UX skills. The design blends monochrome editorial typography with advanced micro-interactions and physics-based animations.

![Portfolio Preview](https://via.placeholder.com/1200x600?text=Portfolio+Preview)

## ✨ Key Features

- **Interactive Mind Map:** An explorative node-graph built with `@xyflow/react` and a custom physics engine (BFS + Spring physics) that dynamically reorganizes nodes when clicked.
- **3D Layered Cards:** Dynamic UI cards that stack, overlap, and transition smoothly using `framer-motion` when navigating through different topics.
- **Scroll Reveal Animations:** Elements elegantly fade and slide into view as the user scrolls down the page.
- **Custom Polaroid Fan Footer:** A unique footer layout where images are arranged in a semi-circular arc, reacting to hover states with 3D rotation.
- **Minimalist Aesthetic:** A strict monochrome color palette (with subtle orange accents) featuring generous whitespace and clean typography.

## 🛠️ Tech Stack

- **Framework:** [Next.js 14](https://nextjs.org/) (App Router)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Graph/Canvas:** [React Flow (@xyflow/react)](https://reactflow.dev/)
- **Icons:** [Lucide React](https://lucide.dev/)
